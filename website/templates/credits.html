Vertex is an original project - every game is built from scratch. Some games take inspiration from well-known genres (a social-deduction game in the spirit of Among Us, a maze-chase in the spirit of Pac-Man, a draw-and-guess party game in the spirit of Gartic Phone), but no code, art, or assets are copied from anywhere - see Features for the full list of what's built and how each game plays.

Built in Java with BlueJ.
